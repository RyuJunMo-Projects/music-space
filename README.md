# 3D 음악 공간

류준모의 서강대학교 지식융합미디어학부 아트&테크놀로지 학과 선택용 포트폴리오입니다. 빛나는 문을 지나 아웃런, 사이버펑크 골목, 낮의 해변을 걸어 다니는 무료 인터랙티브 체험입니다. 실시간 음악 분석 대신 곡별로 정해 둔 박자에 공간이 반응합니다. 무료·비상업 작품입니다.

PC의 Chrome을 권장합니다. 소리가 납니다.

- 시작 버튼을 클릭한 뒤 WASD로 이동하고 마우스로 둘러봅니다.
- 문 가까이에서 문을 클릭하면 공간에 들어갑니다. 빛나는 출구 문을 클릭하면 로비로 돌아갑니다.
- Esc로 잠시 멈추고, 계속하기 버튼으로 현재 위치에서 이어갑니다.
- 시작 화면과 일시정지 화면의 크레딧에서 음악과 소리의 출처를 확인할 수 있습니다.

음악: Netrum & Halvorsen — Phoenix, Max Brhon — Cyberpunk, Diviners feat. Contacreast — Tropic Love. Music provided by NoCopyrightSounds. 로비 환경음과 발소리: freesound_community, yarzur_ofc · Sound effects from Pixabay (Pixabay Content License). 3D 구현에 three.js(MIT License)를 사용합니다.
